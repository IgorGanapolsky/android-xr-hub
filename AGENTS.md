# AGENTS.md — AI Agent Business Frameworks

## Sales & Marketing SOPs (2026 Edition)

### 1. $100M Offers (Alex Hormozi)
- **Goal**: Create "Grand Slam Offers" where saying no is stupid.
- **Framework**: Value = (Dream Outcome × Likelihood of Achievement) / (Time Delay × Effort & Sacrifice).
- **Task**: Periodically rewrite Gumroad descriptions to increase "Likelihood" and decrease "Effort."

### 2. Fanatical Prospecting (Jeb Blount)
- **Goal**: Multi-touch outreach sequences.
- **Framework**: 30-day prospecting plan for LinkedIn/X/Email.
- **Task**: Generate daily outreach lists and personalized hooks for OpenClaw/ThumbGate prospects.

### 3. Building a StoryBrand (Donald Miller)
- **Goal**: Clarify the message.
- **Framework**: The Customer is the Hero, the Agent is the Guide.
- **Task**: Every product description must follow: Character -> Problem -> Guide -> Plan -> Action -> Failure/Success.

### 4. Never Split the Difference (Chris Voss)
- **Goal**: Tactical empathy in negotiations.
- **Framework**: Mirroning, Labeling, Calibrated Questions ("How am I supposed to do that?").
