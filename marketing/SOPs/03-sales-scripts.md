# SOP: StoryBrand Sales Script (Miller)

## 7-Part Script for Gumroad Description

1. **A Character**: The ambitious Android Developer or Agency Owner.
2. **Has a Problem**: Google I/O is here, hardware is shipping, but your code is stuck in 2D.
3. **And Meets a Guide**: We've been building for the Samsung/Qualcomm ecosystem since the Dec 2024 preview.
4. **Who Gives Them a Plan**: Download the Starter Kit -> Open in Studio -> Hit Run.
5. **And Calls Them to Action**: Buy the $149 Starter Kit.
6. **That Helps Them Avoid Failure**: Don't get left behind in the "Meta-only" walled garden.
7. **And Ends in a Success**: Ship a production-ready spatial app before the end of I/O week.
